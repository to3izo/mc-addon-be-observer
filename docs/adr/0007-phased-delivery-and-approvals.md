# ADR-0007: 段階に分けて作り、段階ごとに完了の条件と承認を置く

- 状態: 採用
- 日付: 2026-10-18
- 決定者: 運営（利用者の承認）

## 背景
観測アドオンは、要求の受け渡し（`/scriptevent` と標準出力）が実機で成り立つかどうかに、すべての機能が依存する。BDS の通信アダプター（ADR-0004）は、必要かどうかがまだ分からない。そこで、どの順で作り、どこで止めて判断するかを先に決めた。2026-10-18 に、初期設定と調査のあとの計画（当時の `docs/PLAN.md`。いまは `docs/ROADMAP.md` とこの ADR に移した）が承認された。

## 決定

### 段階と完了の条件
| 段階 | 内容 | 完了の条件 |
| --- | --- | --- |
| Phase 1 | 最小の経路: 観測コア＋`/scriptevent`＋1 行 JSON のログ。`capabilities`・`players` | `pnpm validate && pnpm build && pnpm test` が通る。BDS で `capabilities` と `players` の応答を外部（標準出力）から読めた記録がある。制約が SPEC と PROTOCOL に書かれている |
| Phase 2 | 主な観測（`player`・`block`/`blocks`・`target`・`entities`・追加の項目・`snapshot`）と、プロトコル v1 の確定 | `AGENTS.md` の Definition of Done をすべて満たし、ゲーム内の確認の結果が BDS で記録されている |
| Phase 3 | BDS からネットワークで送る仕組み（必要な場合だけ） | ADR-0004 を「採用」にした場合だけ進める。条件は ADR-0004 |
| 初回リリース | README、バージョン、リリース前チェック、公開 | `docs/TESTING.md` のリリース前チェックリスト |

- 進捗は `docs/ROADMAP.md` のチェックリストで管理する。
- 段階の途中で分かったことによって決定を変えるときは、その段階の ADR に経過を足し、ROADMAP を直す。

### 承認した判断（2026-10-18）
1. 計画どおりに Phase 1 に進む。機能は、計画の承認のあとにだけ実装する。
2. Phase 1 の入口は `/scriptevent` だけにする（ADR-0003）。チートなしのカスタムコマンドを足すかは、Phase 2 で実機の確認のあとに判断する。
3. BDS の設定の変更: 当初は「エージェントは変えない」とした。その後、利用者が BDS への変更を許可した（下の経過）。
4. BDS の公開範囲を絞る作業（`docs/knowledge/bds-local-server/` §6）は、人が判断して行う。
5. 通信アダプターは別のリポジトリに分け、採るかどうかは Phase 2 のあとに決める（ADR-0004）。
6. ADR-0002 の「1.0.0」の意味は、最初のリリースの前に決め直す（ADR-0002）。
7. 上限値の初期値は、`maxRequestChars` 2048、`maxResponseChars` 4000、ブロック 32、レイの距離 64、半径 32、エンティティ 32、インベントリのスロット 54 とする。Phase 1・2 の実測で調整する。
8. README（英・日）は、Phase 2 の終わりに、テンプレートの説明から利用者向けの説明に書き換える。

## 理由・検討した案
- 経路の確認を最初の段階に分けたのは、経路が成り立たないと、後の観測機能をすべて作り直すことになるため。実際に、Phase 1 で次のことが分かり、仕様を直した（ADR-0003・ADR-0006）。
  - BDS の設定が要ること
  - 文字コードの問題
  - チャットのコマンドの長さで切断されること
- 一度に全機能を作る案は採らなかった。ゲーム内の確認の結果で設計が変わる部分が大きいため。
- Phase 3 を最初から計画に入れる案も採らなかった。ベータ版と実験的機能が要り（ADR-0001）、標準出力での回収で足りる可能性があるため。

## 影響
- `docs/ROADMAP.md`: 段階ごとのチェックリストと、未確認の事項。
- `docs/TESTING.md`: 段階ごとのゲーム内の確認の結果。
- 判断が要る項目は、ROADMAP の「判断」の項目として残し、決めたら ADR に書く。

## 経過
- 2026-10-18: 計画を承認（上の 1〜8）。Phase 1 を実装した。
- 2026-10-18: 利用者が「BDS でしか利用できないものとして開発する」と指示し、BDS への変更を許可した（ADR-0006）。Phase 1 を BDS 1.26.52.3 で確認した。
- 2026-10-18: 利用者の指示で、このセッションの作業は、ブランチを作らず `main` に直接コミットした。これは `AGENTS.md` の Git policy（ブランチと PR）の例外で、このセッションだけに認められたもの。以後の作業は、指示がなければ `AGENTS.md` に従う。
- 2026-10-18: `docs/PLAN.md` を廃止した。進捗と手順は `docs/ROADMAP.md`、決定はこの ADR と ADR-0004 に移した。
