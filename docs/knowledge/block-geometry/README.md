# ブロックのモデルとマテリアル

## X 軸が反転している（実機で確認済み、iOS 1.26.50）

- ブロックのモデル（`RP/models/blocks/*.geo.json`）では **+X が西**です。-Z が北、+Y が上です。Blockbench は Bedrock 形式で書き出すときに X を反転するため、手書きやツールで生成したモデルは東西が逆になります。
- `uv` の面の名前（`"east"`、`"west"` など）はワールドの方角のままです。反転しているのはキューブの**位置**だけです。キューブをワールドの向きで考えて作るなら、`origin.x = -(x + size.x)` として書き出します。
- **反転を忘れたときの症状:** 東側にあるべきものが西側に出ます。隣に応じて表示を変える部位では、継ぎ目の線が間違った場所に出ます（6個並べた列で、1|2 と 5|6 の境目にだけ線が出て、両端の枠が消えた）。
- 当たり判定と選択範囲の座標は、ワールドの向きのまま書いて問題は起きませんでした。ただし左右非対称なブロックでは確認してください。

## アンビエントオクルージョンが既定で有効（実機で確認済み、iOS 1.26.50）

- `minecraft:material_instances` の `ambient_occlusion` は、format 1.26.20 から小数の値になり、省略すると **1.0** になります。
- ブロックの縁に近い細い部位（1 ピクセルの枠や縁取り）は、不透明なブロックの隣でそのブロックの色に暗く塗られ、消えたように見えます。バニラのガラスには AO がかかりません。
- ガラスのような素材や装飾用のマテリアルでは、すべてのマテリアルに `"ambient_occlusion": 0` を指定します。

## バニラのテクスチャの一部だけを使う（実機で確認済み、iOS 1.26.50）

- バニラのガラスのテクスチャ（`glass`、`<色>_stained_glass`、`tinted_glass`）は 16×16 で、外周 1 ピクセルが枠、内側 14×14 がガラス面です。`*_pane_top` は全面が塗られています。
- 面ごとの `uv` と `uv_size` で、テクスチャの任意の範囲を切り出せます。
  - 枠のない面: `uv [1, 1]`、`uv_size [14, 14]` を 16×16 の面に引き伸ばす（光の筋が約 14% 太くなるが、ほとんど気にならない）。
  - 枠の帯: `uv [0, 0]`、`uv_size [16, 1]`（外周の1列）。
- 名前付きのマテリアル（面の uv に `"material_instance": "frame"` と書く）を使うと、1つのモデルで複数のテクスチャを使い分けられます。対応するテクスチャは `minecraft:material_instances` で指定します。

## 重ね描きの帯がちらつかないようにする（実機で確認済み）

- 面の上に重ねて描く帯（枠など）を面とまったく同じ平面に置くと、ちらつきます。0.05 ピクセルずらす（立方体のブロックなら内側へ、薄い板なら外側へ）と、iOS では問題が出ませんでした。
- モデルは 16 ピクセルのマスからはみ出しても描画されます（y 16〜17 に置いた部位が正しく表示された）。

## 描画方式（公式資料）

- `alpha_test_single_sided`: 透明なガラス（バニラもこれ）。
- `blend`: 色付きガラスなど半透明のもの。
- `alpha_test` と `double_sided`: 裏面も描画する（背面カリングなし）。
