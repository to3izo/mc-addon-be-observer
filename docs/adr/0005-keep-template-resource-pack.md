# ADR-0005: 中身のないリソースパックを、テンプレートどおり残す

- 状態: 採用
- 日付: 2026-10-18
- 決定者: 運営

## 背景
観測アドオンには、見た目や音などのリソースが要らない。一方、テンプレートは「BP と RP を 1 つずつ、UUID で互いに依存させる」構成を前提にしていて（協調型アドオンのガイドラインの構成。`pnpm init:addon` が書き込み、`pnpm validate --strict` が確かめる）、RP をなくすと道具の作り替えが必要になる。

## 決定
- `resource_pack/` は、`manifest.json` と `pack_icon.png` だけのまま残す。テクスチャ・モデル・音・`.lang`・UI は追加しない。
- 人向けの GUI（server-ui のフォームなど）も作らない（`docs/SPEC.md` の Non-goals）。

## 理由・検討した案
- RP を消す: `tools/` の build・validate・package と、BP の依存の検査を作り替える必要があり、テンプレート全体に影響する。得られるのは数 KB の削減だけなので採らない。
- 中身のない RP は、ゲームの動作にもワールドにも影響しない。

## 影響
- 配布物 `.mcaddon` には、BP と中身のない RP が入る。
- 将来、リソースが必要になったら、この ADR を見直す。

## 経過
- 2026-10-18: 初期設定で決定。
