# ADR-0001: 実験的機能を使わない

- 状態: 採用
- 日付: 2026-10-18
- 決定者: 運営

## 背景
協調型アドオンのガイドラインでは、実験的機能に頼らないことが求められる（`AGENTS.md` の Cooperative Add-On policy）。実験的機能を有効にしたワールドは、実績が解除されず、あとからオフにもできない。

## 決定
- 実験的機能のトグルが必要なコンポーネント、フィールド、フォーマットのバージョン、ベータ版の Script API は使わない。
- 使えない機能は、実験的機能なしの方法で代替する。代替できないときは、機能のほうを諦める（受け入れた制約として、この ADR か別の ADR に書く）。

## 理由・検討した案
- 利用者のワールドに、実験的機能を有効にさせずに済む（有効にすると、あとから戻せない）。
- 実験的機能は、バージョンごとに変わりやすく、リリース後の更新で壊れやすい。
- 「スキーマやサンプルがあること」は、「実験的機能ではない」ことの証拠にならない。判断は、Bedrock Wiki の履歴（`blocks/block-format-history` など）か、実機でする（`docs/knowledge/vanilla-reference/`）。

## 影響
- `pnpm validate` と、`behavior_pack/AGENTS.md` の規則（experimental を使わない）で確認する。
- 実験的機能がないと実現できない機能は、設計の最大の制約になりうる。このリポジトリでの実例は、ベータ版の `@minecraft/server-net` が要るため通信アダプターを却下した ADR-0004。
- 将来、実験的機能が正式になったときの見直し先は、各 ADR の「経過」に書く。

## 経過
- 2026-10-18: Bedrock Observer の初期設定で見直し、このアドオンでも採用した。観測コア（通常ワールドと BDS の両方で動く、安定版 `@minecraft/server` だけを使う部分）は、この ADR に従う。
- 2026-10-18: 利用者が Marketplace には出さないと決めた（ADR-0006）。理由から「Marketplace に提出できない」を外し、ワールドを戻せないことを理由にした。決定は変えない。
- 2026-10-18: `@minecraft/server-net`（と `@minecraft/server-admin`）は、BDS 専用で、公開版がすべてベータであり、ワールドで実験的機能「Beta APIs」を有効にする必要がある（公式資料。`docs/RESEARCH.md` §2.4）。そのため、BDS 専用の通信アダプターは、この ADR の例外になり、観測コアの配布物には入れない。採るかどうかと、例外の範囲は ADR-0004 で扱う（保留中）。
- 2026-10-18: ADR-0004（通信アダプター）を却下した。ベータ版の API を使う部品は作らないので、この ADR の例外は生じない。
